# ColaMD Changelog

欢迎来到 ColaMD 的**可玩 changelog**。面板里列出的就是本目录的文件，点击切换，每个文件演示一组功能（面板默认在右侧，视图菜单里可以换到左边）。每次安装新版本后的首次启动会自动打开这一页。这是演示副本，玩坏了随时可以从仓库恢复。

---

## v2.7.8-rc.2 · 能导出 Word 了，也能把图片排对

**菜单里有了「导出 Word...」。** 选它之后，整篇 Markdown 连同标题层级、有序/无序列表、代码块（每行保留换行，不会被粘成一坨）、带边框和表头底色的表格、引用块、链接、高亮、删除线、脚注，一起进 Word。主题令牌从当前编辑器的计算样式读出来——换一套主题再导出，Word 里的字色、链接色、代码底色、表格表头底色跟着换；没有主题也会用一套浅色默认值，离线脚本直接调用不受影响。公式和 HTML 块先变成截图再嵌进 Word，远程图片也能下载后再进；脚注按正文里第一次引用的顺序编号，页脚带当前页/总页数。

**块级图片现在能居中了。** 以前普通 `![alt](path)` 图片导出后一律靠左，只有公式和 HTML 块那两个特殊前缀的截图才居中。现在所有块级图片统一居中，前后还留了一点呼吸空间。

**行间距不再跟主题脱节。** 以前标题、脚注、代码块的行距都是硬编码数字，换主题调 lineHeight 不会跟着变，有时候看起来就「标题压得太紧、代码块又太松」。现在全部按主题 lineHeight 的相对比例算，正文还多了个小段前留白，段落之间前后看起来均匀。引用块、列表项、代码块的前后 padding 也都改成跟字号联动。

**图片导出那条路子核对过，和上游 2.7.7 一致。** 就是隐藏一个 BrowserWindow 当相机、先等布局稳定、再 `capturePage`，超过 16384 像素设备边的文档自动退回编号页。extend 版唯一一处不同是少了个 `#source-editor` CSS 选择器——上游还留着那套源码 textarea，extend 改成了源码模式和渲染模式共用一个 CodeMirror，那个元素已经不存在了。画公式/HTML 块的截图走的也是同一个相机模式，没有另造一套。

本版代码改动：

- **Word 导出**: `src/main/docx-export.ts` 新增，remark 解析 + docx 生成；主题令牌通道从 renderer 到主进程；公式/HTML 截图用隐藏窗口
- **图片修复**: 所有块级图片统一居中并加前后留白；代码块、列表项、引用块 padding 跟随主题字号
- **行间距联动**: 标题/脚注/代码块行距从硬编码改为 `paragraphLine × 比例`；正文新增小段前留白
- **图片导出一致性**: 与 upstream `v2.7.7` 逐文件 diff，核心链路完全一致，`#source-editor` 选择器移除是架构同步改动
- **版本**: `package.json`、`package-lock.json`、`themes/contract.json` 统一为 `2.7.8-rc.2`

技术细节与验证记录见仓库 `docs/release-2.7.8-rc.2.md`。

## v2.7.8-rc.1 · 安卓版、源码高亮与主题工具链

**安卓版来了。** 同一份编辑器内核现在跑在 Android 上：在系统文件管理器里点一个 `.md` 就能用 ColaMD 打开，应用被系统回收之后从文件管理器再唤起，文件内容也还在；顶栏有一个跟随主题的原生菜单，界面按手机宽度收紧（没有文件列表面板，也没有桌面那套窗口按钮）。`npm run dist:android` 打出 release APK，产物与桌面安装包一起放在 `release/colamd-<版本>-android.apk`。

**源码模式自带 markdown 语法高亮。** 以前切到源码模式（`⌘/`）看到的是一片黑白文字。现在整篇按当前主题上色：标题、加粗、斜体、删除线、链接、行内代码，以及代码块里的关键字与字符串各有颜色，换主题颜色跟着换。它仍然是同一个编辑器，只是把排版那一层收起来，所以切回渲染模式时光标、撤销历史和滚动位置都还在，文字也不会重新解析一遍。

**大文件还是打开就进源码模式。** 半兆以上的文档跳过整篇排版计算，打字不卡；这个视图现在也带语法高亮，处理方式与普通文档一样。

**导出的 HTML 带上图表与块公式了。** 以前图表、块公式这类整块替换的内容会被当成空代码块，导出的 HTML 里只剩一个空的 `<pre><code></code></pre>`。现在它们和屏幕上的排版一起带走，图表颜色由主题变量决定，离线打开也正常。

**给主题工具链的 2.x 渲染器。** npm 包新增 `@bytechain.cn/colamd/renderer` 入口，外部工具可以用应用同一套编辑器和 CSS 做 HTML / PDF 导出；`themes/contract.json` 发布机器可读的主题契约（活变量、死变量、49 个编辑器钩子），`colamd-verify-themes` 命令可以在仓库外对主题文件跑选择器命中检查。

本版代码改动：

- **库渲染器**: `npm run build:lib` 产出 `dist/lib/colamd-renderer.js` 与 `colamd.css`，单文件、字体内联，公开 `createColaMDEditor` 等 API
- **导出变量契约**: 导出的 HTML 只在 `:root` 输出 27 个活变量，图表用的 `--pele-*` 离线也能解析
- **主题契约**: `themes/contract.json` 记录活/死变量、死选择器、49 个编辑器钩子与约束，`verify:theme-contract` 防止与源码漂移
- **独立验收**: 主题命中检查的核心抽成共用模块，新增 `colamd-verify-themes` 命令，仓库内 `verify:themes` 行为不变
- **导出修复**: mermaid 图与块公式不再被当成空代码块，导出的 HTML 会完整带上它们
- **版本**: `package.json`、`package-lock.json`、`themes/contract.json` 统一为 `2.7.8-rc.1`

技术细节与验证记录见仓库 `docs/release-2.7.8-rc.1.md`。

## v2.7.7 · 图表换了引擎，也能放大了

这一版的主角是图表，另外把上一轮改动带出来的几处毛病收干净了。

**画图的那套引擎换成了 Pele。** 以前用 Mermaid，为了画出十几种图，安装包要背上三兆多的脚本，渲染还得塞进一个隐藏的 iframe 里跑，为的是别把打字卡住。Pele 是 Obsidian 团队做的，吃的还是同一份 Mermaid 语法，你文件里写的东西一个字都不用改；整个包六百多 KB，没有运行时依赖，那个 iframe 和配套的超时重置机制一起删掉了。它按图种分开加载：文件里没有图，启动时一分钱不花；有图也只加载用到的那一种。渲染器的体积从 10M 降到 5.4M，一张三百个节点的流程图从占位到画好大约 20 毫秒。图上的颜色现在从当前主题算出来，换主题不用重画，也不再有「按背景明暗挑浅色还是深色」这件事。**图的排版会跟以前不一样**，节点形状、连线弧度、字号都重新排过，这一点得先说清楚。

**放不下的图现在能放大看。** 以前一张横向铺得很开的图，在窄窗口或者开着大纲面板的时候会被压成一条几十像素高的细线，字糊成一团，而它本来只是照容器等比例缩小的。现在这类图角上会出现放大、缩小、还原三个按钮，也可以按住 `Ctrl`（Windows / Linux）或 `Cmd`（macOS）滚滚轮；放大之后按住图可以拖动平移，双击在原始大小和放大之间来回。本来就放得下的图不出现按钮，单用滚轮也还是滚文档，不会被图抢走。导出图片和 PDF 用的是完整的图，不会把放大后的那一角、或者那排按钮画上纸。

**表格点哪一格，光标就落在哪一格。** 以前点渲染出来的表格，光标落在源码第一行开头，而源码正被渲染结果盖着，看起来就是「打完字表格散架了」，其实第一个字写进了你看不见的地方。现在点某一格，光标进到那一格里去，行首带缩进的表格和没有竖线的表格也认得准，光标离开这块又变回排版。表格、图、HTML 块、块公式都按这个规矩来；图片不算，它源码只有一行，本来就在眼前。

**一行链接不会再让整篇正文空白。** 链接里只包一张图（`[![图](a.png)](https://…)`）会让渲染层的排序断言失败，于是整个渲染层被丢掉，文件打开就是空白一片。触发条件很窄，但踩上就是大事，现在修掉了，验收里也钉住了这个写法。

剩下的是小修小补：

- **公式认得 `\[…\]` 和 `\(…\)`**：ChatGPT 这类模型默认用这两个定界符，以前粘进来是原文；现在能认，但会先看内容像不像公式，`\[1\]` 这种编号不会被误判
- **行内 HTML 成对标签只管标签之间的字**：`<span style="color:red">红</span>绿` 以前会把整行都染红
- **选中文字不再给全文同一处都描上框**：每个匹配项都框一遍，看得人眼晕
- **代码块里选中文字看得见高亮**：底色原来压在选区层上面，只剩左右两边各 40px 露出色带
- **导出的 HTML 里不再漏进围栏符号**：代码块结尾那行三个反引号以前会跟着进 `<pre><code>`
- **打开文件面板时正文在可见区域里居中**，不再被面板挤到左边缘
- **渲染进程的运行期报错会写进 `renderer-errors.log`**：白屏这种事后查不出原因的问题，至少留下一条线索

表格格子定位、围栏这两处来自 @wg2038 的贡献，面板那一段接着 @Yesokim 的改动做。

## v2.7.6 · 打开目录，正文让开

这一版只改布局，修一个把阅读位置吃掉的回归。

**打开文件（大纲）面板后，正文不再被面板压住。** 面板是浮在窗口上的一列，从 2.7.3 起正文忘了给它让位，面板越宽、被盖住的越多，滚动条也跟着藏在面板底下。现在正文按面板所在的那一侧让开，并且在剩下的可见区域里居中，面板放左边放右边都对。切到源码模式（`⌘/`）时文字不会横向跳，两种模式落在同一个阅读位置上。

## v2.7.5 · 打开就是干净的排版

这一版把一个模式收掉了。

**标记现在一律不露源码。** 以前光标停在哪一行，那一行的 `**`、`#`、`[]()` 就冒出来等着你改，屏幕上的排版因此一直在变。现在渲染模式下每一行都是干净的排版，要改标记就去源码模式（视图菜单里的「源码模式」，快捷键 `⌘/`）。它照样能编辑，点哪儿写哪儿，只是不再把标记翻出来。屏幕上是排版、文件里是原文，这两件事一直同步，这一点没有变。

**复制粘到别处不再多一个空行。** 文档里每个空行以前都会翻成一个空段落，粘到 Typora 或者其他编辑器里，段落之间就凭空多出一整行。现在空行只是段落分隔。导出 HTML 走的是同一段代码，那个毛病一起修好了。

**`⌘+` / `⌘-` 只放大正文字号，不再缩放整个界面。** 以前它缩的是整页，顶栏跟着一起变高，而 macOS 的红绿灯是系统按窗口画的、尺寸不跟着变，所以放大之后就不居中了。现在界面尺寸一动不动，只有文档跟着变大变小，设置里的字体字号和它同一个值。顺带修了一个上一版引入的问题：只调字号的时候会把主题自己的字体顶掉。`⌘0` 恢复默认字号，你自己挑过的字体不会被清掉。

## v2.7.4 · 删掉一行，序号就接上了

这一版修的是四处「看着没坏、其实坏了」的地方。

**有序列表删掉中间一项，下面的序号会自己接上。** 以前 `1. 2. 3.` 删掉 `2.` 那行，剩下的是 `1. 3.`，后面要一个个手改。现在序号会跟着你的编辑重排。关键在于改的是**文件本身**，不是只在屏幕上好看：复制出去、用别的软件打开、纯文本导出，序号都是对的，撤销一步能回到改之前。打开文件、Agent 改写文件这些不是你动手的场合，序号一律不动（有人特意把整列写成 `1. 1. 1.` 让 diff 干净，那种写法不会被抹平）。

**查找的「下一个」现在真的会跳。** 以前按下去计数在走、界面不动，得手动滚。这很可能就是 #138 里「搜索没反应」的那个根因：换内核后正文改由编辑器内部的滚动容器托管，跳转还在写外层那个。

**深色主题里选中文字不再被盖住。** 选中色带一直是编辑器内核自带的一套默认色，跟主题无关，深色主题下几乎看不见字。现在跟随主题，各套主题的对比度都回到能正常阅读的范围。

**下载的主题现在真的生效了。** `themes/` 里那 12 份独立主题文件还写着旧内核的选择器（`.ProseMirror`），换内核之后永远匹配不到东西，于是导入一套主题只换了底色，加粗、标题、引用块的颜色纹丝不动。现在全部改成编辑器真实的类名，并且加了一条验收：主题里任何一条规则只要命中不到真实元素，CI 就会红。

顺带两个小的：

- **导出的 HTML 与 PDF 不再丢掉列表起点**：以 `5.` 开头的列表以前会从 1 数起
- **自定义主题多了一份带注释的模板**（`themes/template.css`）：变量和选择器都有现成的写法可以照抄

另外，仓库里那个 VS Code 小扩展（「在 ColaMD 中打开」，0.1.0 的 MVP）撤掉了，一直没维护。

## v2.7.3 · 本地链接能跳了，换内核时漏掉的阅读体验也补回来了



这一版有两块：一块是新能力，一块是把 2.7 换内核时手上漏掉的阅读体验补回来。

**本地链接能跳了。** 在文档里写 `[方案](doc/方案A.md)` 这种相对路径，按住 `Ctrl`（Windows/Linux）或 `Cmd`（macOS）点击，就在标签页里打开对应的文件。绝对路径和 `file://` 也认，中文、空格文件名照常。链接后面还能带位置：`[设计目标](doc/方案A.md#设计目标)` 滚到那个标题，`[第 147 行](doc/方案A.md:147)` 滚到那一行；标题重名时按顺序找第二个、第三个，代码块里写着 `# 注释` 的行不会误判。这条来自社区反馈，实现是 @linxiW1020 写的。

阅读体验这块，都是 2.7 换内核时漏掉的：

- **文首的属性区默认收起了**：从 2.6 升上来的话，第一眼就会看到 2.7 把那段 YAML 一直露在正文最上面。现在整块收起，光标移进去才显示
- **表格格子里的 `<br/>` 真的换行了**，格子里放图片也能显示
- **表格、图、图片、公式、HTML 这些渲染出来的块，点一下就进到源码**：以前只有公式有这条路，别的块只能去改源文件
- **打开文件夹面板后，正文不再往右偏**：换内核时留下的三条旧样式还在给编辑器加边距，而面板现在是独立占一列，那三条等于又推了一把
- **大纲不再把代码块里的 `#` 当成标题**
- **待办事项选中时不再是 `- [ ]` 源码**：复选框一直在，勾没勾还是点出来
- **属性区认中文键**：`标题: 值` 这种以前会被当成正文

Linux 的 AppImage 换了一套图标：以前只带一张 1024px，菜单和任务栏按标准尺寸去找都找不到，只能退成通用图标；桌面项里的窗口类和 Electron 实际的窗口类也对不上，运行中的窗口关联不到图标。现在整套尺寸都带上，类名也钉住了。

还有一个小的：加粗的时间戳（`**00:28:02 开场**`）以前会被染成绿色，因为 markdown 语法把 `:00:` 当成了 emoji 的短代码。

## v2.7.2 · 新内核的第一个稳定版

如果你从 2.6.0 直接升上来，这一版最大的变化是编辑器换了内核。以前 ColaMD 打开文件会先把内容解析成自己内部的一份副本，保存时再从那份副本重新生成文件，于是你从没碰过的字符也会被改写：表格的分隔行被压缩、`*` `$` `_` 被加上反斜杠。现在编辑器里存的就是文件的字节，渲染只是叠在上面的一层装饰，打开什么样，保存就还是什么样。长文档导出 PDF 和图片不再只有一屏；图片、脚注悬停、Mermaid 图、代码高亮、公式就地编辑也在这一版补齐，细节见下面 v2.7.0 那一篇。

测试版期间收到的修复：

- **⌘W 关掉最后一个标签，关的就是窗口**：以前它会永远补一个空白标签出来，窗口怎么都关不掉。有未保存内容的窗口照旧先问你怎么存
- **全选不再把整屏翻成 markdown 源码**：只有光标裸露的那一行才露源码，一拉选区整屏保持渲染；顺带修了大选区复制到 Word、飞书粘不出排版的问题
- **白屏有了线索**：编辑器初始化失败时，错误会写进 `userData/renderer-errors.log`，不再只有一个白窗口

## v2.7.1-beta.1 · 选中一段就不再翻成源码

这一版只有一个改动，来自反馈。

以前光标所在的行会露出 markdown 源码，方便你改标记。但「所在的行」是按选区算的，所以全选会让整屏变成 markdown。全选恰恰是最常做的动作，复制、查找、替换都要用到它，每次都被顶一屏源码，很吵。

现在只有光标落在某一行、而且没有选中任何内容时，那一行才露源码。一旦拉出选区，整屏保持渲染。Typora 和 Obsidian 都是这个规矩。

还有一个同源的修复：**全选复制到 Word、飞书这类地方，现在也能粘出排版了**。以前选区一大（超过一屏），富文本口味就给不出来，粘过去只有 markdown 原文。现在会先把整篇渲染出来再取富文本，代价是多花几十毫秒。

另外从这一版开始，测试版的版本号带 `-beta`。装了它之后，应用里的「检查更新」就能直接升到后续的测试版和正式版，不用再手动下载安装。

## v2.7.0 · 文件是唯一的真相

这一版换掉了编辑器的内核。

以前 ColaMD 打开一个文件，会先把内容解析成自己内部的一份副本，保存时再从那份副本重新生成文件。于是你从没碰过的字符也会被改写：表格的分隔行被压缩、`*` `$` `_` 被加上反斜杠、有些加粗会变成一串看不懂的字。

现在编辑器里存的就是文件的字节，渲染只是叠在字节上面的一层装饰。你打开什么样，保存就还是什么样。

为什么值得为这一件事重写整个内核：我们希望十年后你还能用 ColaMD 打开今天写的笔记，那就不能让你的内容依赖某个软件内部的数据结构。文件是唯一的真相，ColaMD 只是让它看起来更舒服的那一层。

- **长文档导出不再只有一屏**：以前导出 PDF 或图片，只印出屏幕上看得见的那一段，后面的内容全丢。现在整篇都印
- **补齐了一批功能**：图片、链接、脚注（悬停看内容）、HTML 片段、Mermaid 图表、代码块的语法高亮和复制按钮、列表回车自动续行、Tab 缩进
- **公式**：点击公式直接就地编辑，弹层去掉了；`$349` 这种价格不会再被当成公式
- **复制**：复制出来的是 markdown 原文，粘到 Typora、Word 里结构和排版都在
- **观感**：和以前基本一致，个别间距有几个像素的差别

这是一次内核重写，改动面很大。如果你遇到显示异常，或者觉得哪里和以前不一样，欢迎开一个 Issue 说一声，附上截图（方便的话连文件一起，脱敏后）。想先用回老版本，2.6.0 的安装包还在 Release 页。

## v2.6.0 · 图跟着文档进 Word，稿子丢了也找得回来

- **导出的 Word 里带上 Mermaid 图**：以前 Word 里只有图的源码，因为 Word 导出走的是 Markdown 那条路，看不懂图。现在每个图都会画成图片放进文档，用的是浅色配色（Word 是白纸，屏幕上那张可能是深色的），正在改源码的图块、甚至整个源码模式下导出，图照样在。画不出来的图保持代码块，不会因为一张图让整次导出失败
- **正文宽度三档**：视图 → 正文宽度，窄 640 / 标准 780 / 宽 1080。宽屏上不再只是中间窄窄一条；切到源码模式文字位置和正文对齐，导出的 HTML 和 PDF 也跟着走（导出的图片不受影响，它有自己的阅读宽度）
- **丢弃未保存内容之前，先留一份副本**：外部改过文件、你选了「加载磁盘版本」时，这是全应用唯一一个会把你的输入就地抹掉的动作。现在被丢弃的那份会先写到 `~/.colamd/recovered`，对话框的按钮上就写着这件事，标题栏随后告诉你去哪找，点一下直接在文件管理器里亮出来。副本写不成功就不丢弃，编辑器保住你的版本
- **标签关闭按钮好点了**：可见的叉号还是 16×16，但可点的范围扩到了 24×24，不用再对准

## v2.5.0 · 把文档当幻灯片放，把幻灯片带出门

- **放映幻灯片**：视图菜单（⌘⇧P）把文档变成全屏的幻灯片，一条 `---` 一页，从你光标所在的页开始放。切的是渲染后的文档，所以主题的字体、表格、公式、代码高亮、图片和 Mermaid 图原样上屏；代码块里的 `---` 不会误分页。方向键 / 空格 / 单击翻页，右键回上一页，Esc 退出后落回你刚才看到的那一页
- **导出幻灯片 PDF**：文件菜单新增一项，把同一套分页印成 16:9 横版 PDF（13.33 × 7.5 英寸），主题纸色、垂直居中。放出去讲，或者发给没装 ColaMD 的人
- **空行不再写成 `<br />`**：以前编辑时多按的每个回车都会在文件里落一个 HTML 标签，源码里看着很不原生，其他编辑器还会把它当正文显示。现在空行就是 Markdown 本来的空行；旧文件里已有的 `<br />` 读进来不受影响，下次保存时自然消失

## v2.4.4 · 你的属性区不再被改写

- **带 YAML frontmatter 的笔记不再被改写**：以前打开这类文件、一个字都不改直接保存，`---` 之间的内容就会被重排成非法 YAML，Obsidian 的属性面板、标签检索、Dataview 会跟着一起失效。现在这一块不进编辑器，保存时按字节原样写回
- **CRLF 的文件保存后还是 CRLF**：以前整份会被改写成 LF，Windows 上编辑过的文件在 git 里显示整篇都变了
- **导出 PDF 时表格不再被切掉最后一列**：单元格里不能换行的长内容（JSON、长链接）会给表格定一个缩不下去的最小宽度，表格撑出纸面。现在打印时长 token 会断行
- **文件列表可以放到左侧**：视图菜单里二选一，默认在右边。只有面板、它的边缘线和它占的那一列换边，顶行和右端三个按钮都不动
- **从 Finder 打开的文件会落进你正在看的那个窗口**，查找替换框也不再被右上角的窗口按钮压住

## v2.4.3 · Windows 窗口按钮的颜色跟着主题了

- **换主题后窗口按钮不再无动于衷**：系统那三个按钮的颜色由我们交给系统，之前交的是一种系统解析不了的写法，整次设置被拒，按钮就一直停在开窗那一刻的颜色上
- **交给系统失败不再默不作声**：日志里会写明，界面上的错不再靠人眼发现

## v2.4.2 · Windows 顶行的两处修正

- **窗口按钮和行里的图标同一个浓度**：之前交的是正文墨色，它们比行里其他图标都黑；深色主题下正好相反，近白的按钮压在深色行上
- **菜单按钮挪到整行最左端**：Windows 上菜单和选项在左边，右端留给系统的三个按钮。macOS 不变

## v2.4.1 · 全屏、Windows 和更新

- **Windows 顶栏只剩一行**：以前系统标题栏、应用内菜单栏、顶行三条叠在一起。现在窗口按钮由系统画进这一行，颜色跟随主题，菜单移到行首，按 Alt 仍然能唤出系统菜单栏
- **全屏时标签贴到窗口左边**：以前进全屏会空出一块，那是给 macOS 红绿灯留的位置，而全屏下红绿灯并不在
- **Windows 上标签文字不再被切掉底下一截**：中文在 Windows 的字体下比 macOS 略高，名字框刚好只够一行
- **更新更可靠**：升级了底层运行时，修好了 macOS 上「更新下载完、应用退出后没再回来」的问题（机器上有待安装的系统更新时最容易碰到）。如果你的机器上还是 2.4.0，这一次如果点了更新没反应，直接到官网重新下载一次即可

## v2.4.0 · 顶栏重做：左边只有文档，右边是面板

- **文件面板搬到右边**：标签在左，面板在右，打开面板的三个按钮就落在面板上面，按钮和它管的列表待在同一侧。面板越宽正文看得越少，但正文列会在剩下的空间里重新居中
- **标签占满整行**：标签是一整列纸，从窗口上沿一直落进正文；活动标签就是那一列纸本身。宽度有上下限，短名字不会塌成一条，长名字也不会无限长，名字太多时先压缩，压到底才让这一条横向滚动
- **切换面板改用 `⌘\`**：原来是不顺手的 `⌘⇧B`
- **正文第一行有了呼吸**：首行上方留出 40px，和左右、下方一致

## v2.3.0 · 文件夹能展开了

- **文件夹就地展开**：文件面板里点一下文件夹，就在原位往下展开，一层层看到底，不用反复切目录再退回。空文件夹会直接说明它是空的
- **名字太长由浮层说全名**：文件列表里的长文件名不再自己左右滑动，改成在行旁边浮出完整名字
- **启动就是一个标签**：打开应用立刻是一个「未命名」标签，不再出现一块不属于任何标签的欢迎页

## v2.2.0 · 一行顶栏，处处跟主题

- **顶部永远只有一行**：标签栏常驻，一个文档也是一个标签，和标题栏合成一行，窗口顶部不再随着开第二个文档而变一副样子
- **右键标签，在新窗口打开**：想把某份文档挪到独立窗口时不用再绕路
- **再打开文件，落成标签页**：双开图标、拖进来的文件不会再启动第二个实例
- **记住窗口大小和缩放**：下次启动按上次的尺寸和缩放打开；外接屏幕拔掉后也不会把窗口开到看不见的地方
- **PDF 导出像纸了**：上下 20mm、左右 18mm 的页边距，页面底色跟随主题，深色主题导出的 PDF 不再是白纸圈黑字
- **「格式」子菜单**：加粗 `⌘B`、斜体 `⌘I`、行内代码 `⌘E`、删除线 `⌘⇧X`、链接 `⌘K`、无序与有序列表
- **脚注悬停预览**：鼠标停在脚注引用上，浮出它的定义，移开即收

## v2.1.2 · 更安静的标签栏

- **第一个标签贴住窗口左边缘**：以前左边空出一小段，看起来像没对齐
- **去掉选中标签上的主题色细线**：ColaMD 是一块沉浸式的画布，标签栏只是薄薄一层壳，选中状态靠纸张色和底边开口表达就够了

## v2.1.1 · 标签页的手感

- **标签栏右端多了一个加号**：新建标签页的加号就在最后一个标签右边（以前要按 `⌘T` 或走菜单）
- **标签上右键有菜单了**：关闭、关闭其他标签页、关闭右侧标签页，以及复制路径、在 Finder 或资源管理器中显示
- **悬停提示更安静**：鼠标停在标签上一秒后才出现完整名字，而且只在名字被截断时才出现

## v2.1.0 · 标签页

- **标签页**：同一个窗口里可以同时开好几份文档，每个标签自己带着内容、撤销历史、未保存状态和阅读位置，来回切换不会互相影响
- **怎么开**：`⌘T`，或者 File 菜单里的「新建标签页」；在文件列表里 **⌘ 加点击**（Windows / Linux 上是 Ctrl）一个文件，它会在新标签里打开
- **怎么关**：点标签切换，中键点标签、或者 `⌘W` 关闭。只有一个文档时不会出现标签栏，界面和以前完全一样
- **边界**：标签页用完即走。关掉应用不会记住这组标签，也没有固定标签、标签分组、跨窗口拖拽标签这类工作区功能

## v2.0.7 · 更小的包、右键菜单

- **安装包小了一大半**：macOS 不再打包两套 CPU 架构合一的通用包，改成按芯片分别发布，因为你不再需要为别人的电脑多下一套运行时
- **Windows 免安装版**：新增 zip 版，解压即用，不写注册表，卸载就是删文件夹。代价是不注册 `.md` 文件关联，也不支持应用内更新
- **文件面板右键菜单**：可以复制路径、用默认应用打开、在 Finder 或资源管理器中显示

## v2.0.6 · 打开所在文件夹修好了

- **「打开所在文件夹」修好了**：这个按钮从 2.0.4 起就在标题栏里，但一次代码重构把它的接线删掉了，按钮一直停在禁用状态（[#83](https://github.com/marswaveai/ColaMD/issues/83)，[#84](https://github.com/marswaveai/ColaMD/pull/84)，感谢 @moyu12-ae）
- **提示标签不再「穿透」**：悬停标题栏按钮时，提示标签此前被画在正文下面，看起来像半透明压在文字上

## v2.0.5 · 稳定性修复

- **撤销不再跨文档**：同一窗口切换文件后，撤销不会再把你带回上一篇文章的内容，也不会因此让自动保存把上一篇误写进当前文件
- **复制不再多空行**：复制到微信、钉钉等聊天工具时，不再多出一堆空行
- **输入更轻**：大纲面板隐藏时不再每帧重建，长文档打字的负担更小
- **PDF 导出修复**：导出时不再把更新提示等浮层当成正文（[#71](https://github.com/marswaveai/ColaMD/issues/71)）
- **移除 Agent 活动指示器**：它只能根据文件变化的时间间隔猜测，无法区分 Agent 与其他外部写入，而内容实时更新本身已经说明了一切

## v2.0.3 · 查找替换与更可靠的更新

- **大文档打开优化**：超过 512 KiB 的 Markdown 直接以源码模式打开，避免 Windows 上完整可视化解析造成长时间卡顿（[#63](https://github.com/marswaveai/ColaMD/issues/63)）
- **查找与替换**：⌘F 查找面板支持替换当前匹配项或全部替换（⌘/Ctrl+Enter），所见即所得与源码模式均可用
- **界面语言切换**：「视图 → 界面语言」可选中文或 English，全界面即时生效并记住选择
- **更新下载反馈**：更新横幅实时显示下载进度，下载失败会提示并可重试，不再停留在「下载中」
- **增量更新**：发布产物附带 blockmap，自动更新改为只下载变更部分

## v2.0.2 · 可调面板与大纲进度

- **文件面板可调宽**：拖拽面板边缘即可调整宽度（180–420px），应用会记住你的选择
- **大纲进度视图**：阅读时大纲自动高亮当前章节；点击大纲或文内锚点跳转后，落点标题会闪一次主题色高亮带（[#64](https://github.com/marswaveai/ColaMD/issues/64)）

## 模拟 Agent

打开终端，对当前目录做点改动，窗口会实时响应：

```bash
echo '- [ ] 这是 Agent 刚写入的任务' >> tasks.md
echo '# 全新文件' > new.md
```

第二行会**实时**出现在文件面板里，面板和内容一起动。

Markdown 语法请使用 Help 中的主入口，内容会根据系统语言自动选择。
