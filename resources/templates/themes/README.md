# 扩展主题：图表配色契约（Pele 引擎）

上游 2.7.7 起图表引擎换成 Pele：SVG 直接画进编辑器文档，图里的颜色写的是
`var(--pele-*)`，在图落进的文档里取值——所以主题想给图表配色，就是覆盖下面
这组 CSS 变量，纯 CSS、无 JS 管道、换主题即时生效（不用重画、不用刷新）。

## 变量一览

| CSS 变量 | 画的是什么 | 缺省时的取值 |
| --- | --- | --- |
| `--pele-bg` | 画布底色 | `--code-block-bg` |
| `--pele-fg` | 文字 | `--code-block-text` |
| `--pele-muted` | 弱化文字 | 文字色与底色 70% 混合 |
| `--pele-line` | 连线与箭头 | `--code-block-text` |
| `--pele-surface` | 节点填充 | 文字色 18% 与底色混合 |
| `--pele-surface-alt` | 次级节点填充 | 文字色 28% 与底色混合 |
| `--pele-border` | 节点描边 | 文字色 45% 与底色混合 |
| `--pele-accent` | 强调色 | `--link-color` |
| `--pele-radius` | 圆角 | `6px` |

## 规则

- **声明在 `:root` 上。** 主题的根块（`:root`）里覆盖即可，编辑器文档能继承到；
  写在别的选择器里等于没写。
- **不必写齐。** 每个变量独立生效，没写的落缺省列——缺省值本身就是从代码块
  底色和字色推出来的，对比度是算出来的。想改哪一档就写哪一档。
- **图直接画在代码块背景上。** 配色贴着 `--code-block-bg` 调：深色代码块配深色
  图表底、浅色连线（本目录各主题的图表配色段落就是范例，抄一段改色值即可）。
- **切主题即时生效。** SVG 内嵌 `var()` 取值，主题换装后图自动跟随，不需要重画。
- **Word 导出画在固定白底上**，Pele 的变量到不了 `<img>` 的 data URL，
  会内联一套浅色值（mermaid-bridge.ts 的 `PRINT_PALETTE`），不读主题变量。
