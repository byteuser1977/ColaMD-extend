# ColaMD v2.7.7 Social Copy

发布方式：正式版。

## Chinese

ColaMD 2.7.7 发布。

**图表引擎换成 Pele。** 语法还是 Mermaid，文件不用改；渲染器体积从 10M 降到 5.4M，按图种分开加载，没有图就不加载。图的排版会和以前不一样。

**放不下的图可以放大看。** 角上有放大、缩小、还原按钮，Ctrl（Windows / Linux）或 Cmd（macOS）加滚轮也可以缩放，放大后能拖动平移。放得下的图不显示按钮，单用滚轮仍是滚文档。

其余改动：

- 点表格某一格，光标落进那一格，带缩进和无边框的表格也认得准
- 光标进到渲染块里会露出该块的源码
- 链接里只包一张图，不再让整篇正文空白
- 公式认得 `\[…\]` 和 `\(…\)`，从 ChatGPT 粘过来可以直接显示
- 行内 HTML 成对标签只作用于标签之间的文字
- 选中文字不再给全文每个匹配处描框
- 代码块里选中文字看得见高亮；导出的 HTML 不再带结尾围栏
- 打开文件面板时，正文在可见区域里居中

感谢 @wg2038（表格格子定位、导出围栏）、@Yesokim（面板动画）、@jianlongliu（#157）。

已装的在菜单里检查更新，没装的去 Release 页下载。文件不用动。

https://github.com/marswaveai/ColaMD/releases/tag/v2.7.7

## English

ColaMD 2.7.7 is out.

**Diagrams are drawn by Pele now.** The syntax is still Mermaid, so your files do not change; the renderer drops from 10 MB to 5.4 MB and loads per diagram type, nothing at all when a document has no diagrams. Diagram layout looks different from before.

**A diagram too wide for the column can be zoomed.** Zoom in, zoom out and reset buttons sit in the corner, Ctrl (Windows/Linux) or Cmd (macOS) plus the wheel works too, and a zoomed diagram can be dragged to pan. Diagrams that already fit show no buttons, and a plain wheel still scrolls the document.

The rest:

- Clicking a table cell puts the cursor in that cell, including indented and borderless tables
- The cursor entering a rendered block reveals that block's source
- A link wrapped around a single image no longer blanks the whole document
- Formulas are recognised with `\[…\]` and `\(…\)`, so text pasted from ChatGPT renders as is
- A paired inline HTML tag styles only the text between its tags
- Selecting text no longer draws a box around every other occurrence
- A selection inside a code block is visible, and exported HTML no longer carries the closing fence
- With the file panel open, the text is centred in the visible area

Thanks to @wg2038 (table cell targets, export fence), @Yesokim (panel animation) and @jianlongliu (#157).

Update from the menu, or download from the Releases page. None of your files need to change.

https://github.com/marswaveai/ColaMD/releases/tag/v2.7.7
