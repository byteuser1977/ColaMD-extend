# ColaMD-extend v2.8.2 Social Copy

发布方式：正式版。本版合入上游 2.8.1 与 2.8.2 的全部改动，并带上扩展版自己的导出增强，统一按 v2.8.2 发布。

## 主文案（直接发）

ColaMD 扩展版 2.8.2 发布：表格在渲染模式下直接改，列表支持改起始号与续行缩进，文件列表支持右键重命名，导出继续增强。

- 点表格里的字不再让整张表露出源码，直接在格子里改。拖选格子复制出去，加粗、颜色、行内代码、公式都跟着走。Tab 与 Shift+Tab 在格与格之间移动，⌘Enter 在当前行下方插行。
- 表格里的行内公式、颜色标记与高亮只在自己格子里生效，不再跨竖线把两列并成一列；空单元格里中文组字时点到别处，已输入的字留在原格。
- 双击有序列表的序号可直接修改起始数字，同组后续编号自动顺延。在列表中间插入普通行后按 Tab 对齐上一项正文并接回编号，Shift+Tab 或行首退格一次退回顶格。
- 侧栏文件列表支持右键重命名，改名后标签页标题、路径与当前编辑状态同步更新。
- 导出时隐藏 HTML 注释：`<!-- … -->` 是写给看源码的人的，导出的 PDF、HTML 与打印结果里不再出现。
- 修复源码模式的大纲定位与查找滚动、引用空行露出 `>`、Word 导出列表项以表格或代码块开头段落顺序颠倒等问题。
- 修好幻灯片导出时多页内容挤在一张纸上的问题：页首标记以前落在 `---` 后的空行上，被分隔 widget 替换后失效，现在顺延到每页第一个有字的行，打印前重新锚定。
- 放映的页顶安全区改写在页面容器上按 1080p 取 24px，section 版式改为顶部对齐，导出与放映保持一致。

https://github.com/byteuser1977/ColaMD-extend/releases/tag/v2.8.2

## English

ColaMD-extend 2.8.2 is out: tables edit in place in rendered mode, ordered lists gain start-number editing and continuation indentation, the file list supports right-click renaming, and exports improve further.

- Click a cell and type, no more whole-table source view. Dragging across cells copies text with bold, colors, inline code and math intact. Tab and Shift+Tab move between cells, Cmd+Enter inserts a row below.
- Inline math, colored spans and highlights inside a table stay within their own cell; text typed with an IME in an empty cell stays in that cell when you click elsewhere.
- Double-click an ordered list number to change its starting value, with following items renumbering in sequence; Tab inside a list aligns to the previous item, Shift+Tab or Backspace returns cleanly to column 0.
- Right-click any file in the sidebar to rename it in place, keeping the open tab title, path and editor state in sync.
- Exports hide HTML comments: `<!-- … -->` is written for source readers, and no longer appears in exported PDF, HTML or print output.
- Fixes include source-mode outline navigation and find scrolling, empty quote lines leaking a raw `>`, and Word export putting list paragraphs ahead of leading tables or code blocks.
- Slide export no longer collapses a multi-page deck onto one sheet: page starts used to land on the blank line after `---` and were lost to separator widgets, and now move to the first line with content and are re-anchored before printing.
- The presentation's top safe area lives on the page container at 24px per 1080p, section pages align to the top, and export matches the presentation.
