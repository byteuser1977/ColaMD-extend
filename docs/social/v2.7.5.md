# ColaMD v2.7.5 Social Copy

发布方式：正式版。

## Chinese

ColaMD 2.7.5 发布了。这一版把一个模式收掉了。

**标记现在一律不露源码。** 以前光标停在哪一行，那一行的 `**`、`#`、`[]()` 就会冒出来等着你改，屏幕上的排版一直在变。现在渲染模式下每一行都是干净的排版，要改标记就去源码模式（视图菜单里的「源码模式」，快捷键 `⌘/`）。它照样能编辑，点哪儿写哪儿，只是不再把标记翻出来。屏幕上是排版、文件里是原文，这两件事一直同步，这一点没有变。

**复制粘到别处不再多一个空行。** 文档里每个空行以前都会翻成一个空段落，粘到 Typora 或者其他编辑器里，段落之间就凭空多出一整行。现在空行只是段落分隔。导出 HTML 走的是同一段代码，那个毛病一起修好了。

**`⌘+` / `⌘-` 只放大正文字号，不再缩放整个界面。** 以前它缩的是整页，顶栏跟着一起变高，而 macOS 的红绿灯是系统按窗口画的、尺寸不跟着变，所以放大之后就不居中了。现在界面尺寸一动不动，只有文档跟着变大变小，设置里的字体字号和它同一个值。顺带修了一个上一版引入的问题：只调字号的时候会把主题自己的字体顶掉。`⌘0` 恢复默认字号，你自己挑过的字体不会被清掉。

如果你上面哪一条还复现，欢迎开 issue。

## English

ColaMD 2.7.5 is out. This release removes a mode.

**Markup never shows itself now.** Before, the line your caret sat on revealed its own `**`, `#` and `[]()` so you could edit them, which meant the page kept changing shape under the cursor. In the rendered view every line is now clean typography, and markup is edited in source mode (View → Source Mode, `Cmd+/`). The rendered view is still editable: click where you want to type and type. What you see on screen and what is in the file stay in sync, exactly as before.

**Copying no longer adds a blank line.** Every blank line in a document used to be rendered as an empty paragraph, so pasting into Typora or another editor produced an extra blank line between paragraphs. A blank line is now just a paragraph break. The HTML export shares that code, so its version of the bug is fixed too.

**`Cmd+` / `Cmd-` now change only the text size.** They used to zoom the whole window, chrome included, while the macOS traffic lights are drawn by the system at a fixed size, so they ended up off centre once you zoomed in. Interface sizes no longer move; only the document grows and shrinks, sharing one value with the font size in settings. The same change fixes a problem the previous release introduced, where changing only the size pushed the theme's own font aside. `Cmd0` restores the default size and keeps a font you picked yourself.

If any of the above still reproduces for you, please open an issue.
