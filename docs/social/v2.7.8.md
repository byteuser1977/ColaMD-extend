## Chinese

ColaMD 2.7.8 发布。没有新功能，只有七处「看得见但说不出哪里不对」。

**代码块里的光标和选中范围看得见了。** 雅致、熊红这两套主题的代码块是深底，光标和拖放时的落点竖线一直吃正文色，进去就消失。现在它们跟着代码块自己的文字色走，离开代码块就换回来。

同一类问题还有两处：引用里的代码块被引用的底色盖住，浅色字落在浅色底上几乎看不清，nord、dracula 那几套则是代码字被染成引用色；引用里拖选文字，选中的范围也被底色压在下面。现在按背景、选区、文字的顺序重新叠好了，引用左边那条竖线保留。

**导出的 HTML 跟屏幕是同一套配色。** 雅致、熊红导出后代码块只剩一片深色底，字和背景同色。现在导出用的是主题自己那套代码文字色。

**导出的 HTML 不再丢图表、不再拆散列表。** 已渲染的图表那一行还带着代码块标记，被当成代码围栏清理掉了；列表项里的表格会跑到列表外，续段变成新的列表项。现在这些都按原结构导出，有序列表的起始编号也保留。

**`⌘/` 现在真的切换源码。** 以前它会把当前行包成 `<!-- 注释 -->`，因为编辑器自带的按键表把 `Mod-/` 绑给了「切换注释」。现在正文和源码里都切得动，切完焦点落在编辑区，`⌘A` 只选中正文，文字位置和选区方向都保留。

顺手收掉的几处：退出源码编辑后图表立刻回来；词中间的 `_` 不再被当成斜体（`local_upload` 这类名字）；复选框只在它自己身上响应，光标不钻进 `- [ ]`；标题上方的间距补回来了。

七条修复来自 @Michael8021 报的 issue 和配套 PR，引用里的代码块、列表导出那几处根因都是他自己查出来的。

已装的在菜单里检查更新，没装的去 Release 页下载。文件不用动。

## English

ColaMD 2.7.8 is out. No new features, seven fixes for things that looked wrong without being obvious.

**Cursors and selections are visible inside code blocks again.** In the Elegant and Bear themes the code block is dark while the caret and the drop indicator kept using the body text colour, so both vanished. They now follow the code text colour.

The same class of bug appeared twice more: a code block inside a quote was covered by the quote background (and in nord and dracula its text took the quote colour), and a selection inside a quote sat under the quote background. Background, selection and text are now stacked in that order, and the quote bar stays.

**The exported HTML uses the same palette as the screen.** Exporting with Elegant or Bear left a dark code block with text of the same dark colour; the export stylesheet set the background but not the text colour.

**The exported HTML no longer loses diagrams or breaks lists.** A rendered diagram's line still carries the code-block class, so fence cleanup removed the whole line including the SVG. A table inside a list item was pushed outside the list, the following paragraph became a new item, and blank lines produced empty items. List ownership now travels from the syntax tree to the export layer, so a numbered item keeps its paragraphs, tables and closing remarks, and ordered lists keep their start number.

**`⌘/` actually toggles source mode.** It used to wrap the current line in an HTML comment, because the editor's own keymap binds `Mod-/` to "toggle comment" and the menu accelerator never saw the key. That binding is gone: `⌘/` (Ctrl+/ on Windows and Linux) switches both ways, focus lands in the editor, `⌘A` selects only the document, and the caret keeps its place.

Also fixed: a diagram comes back right after leaving source mode instead of needing a scroll; `_` inside a word is no longer italic (`local_upload`); the checkbox responds only to itself and the caret no longer enters the `- [ ]` syntax; heading spacing above is restored.

All seven come from issues and pull requests by @Michael8021; the quoted code block and list export root causes were his own findings.

Existing installs: check for updates in the menu. New installs: the Release page.

https://github.com/marswaveai/ColaMD/releases/tag/v2.7.8
