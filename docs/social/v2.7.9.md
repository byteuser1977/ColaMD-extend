## Chinese

ColaMD 2.7.9 发布。这一版只改一件事：正文里的字色。原来引用、列表、加粗各有各的颜色，同一页纸上分出好几等次，看着累。

**列表的文字不再发灰。** 列表里的字整段都是浅灰，只有段落是深的，圆点和序号也一样灰。根因在语法高亮那一层：`t.list` 跟 `#`、`>`、`-` 这些标记字符写在同一条规则里，一起压成了弱化色，而它罩住的是整个列表项的文字，不只是前头那两个字符。现在列表的文字、圆点、序号都用正文色，是列表这件事由缩进自己说清楚。

**引用的文字也不再淡一档。** 引用现在只靠左边那条竖线和底色区别于正文。顺带删掉了 nord、gruvbox、dracula、午夜四套主题里写死的引用字色。

**加粗只靠字重，删除线只靠划线。** 以前加粗在多数主题里会换成一种强调色，删除线会压灰；现在两样都不换颜色。

结果是渲染模式下正文里只剩四种字色：正文、链接、行内代码、代码块里的字。行内代码和代码块本来就是文件里的另一类内容，不是正文字，所以各留一笔颜色。

改了色的地方在十二套主题下都量过：引用、列表、加粗、删除线的文字色全部等于正文色。验收脚本也补了断言，其中一条是这一轮踩出来的教训：以前量的是行元素的颜色，而行元素一直报正文色，于是断言全绿、屏幕上还是灰的；现在量的是文字落在的那个元素。

## English

ColaMD 2.7.9 is out. This release changes one thing: the text colours inside the document.

**List text is no longer grey.** Every list item used to be tinted down to a muted grey, bullets and numbers included, while paragraphs stayed full strength. The cause was a single syntax-highlight rule that grouped the list node together with the `#`, `>` and `-` marker characters and muted them all; the list node covers the whole item's text, not just those two characters. List text, bullets and numbers now use the body colour. The indent already says it is a list.

**Quotes are no longer a shade lighter.** A quote is now told apart by its left rule and background only. The four themes that hard-coded a quote colour lost it.

**Bold is weight, strikethrough is a line.** Neither swaps the text colour any more.

Rendered documents are down to four text colours: body, links, inline code and code blocks. Inline code and code blocks are a different kind of content, not body text, so they keep their own colour.

All twelve themes were measured: quote, list, bold and strikethrough text all match the body colour. The verification suite also gained assertions, one of them from a mistake made during this work: earlier assertions measured the colour of the line element, which always reports the body colour, so the suite stayed green while the screen stayed grey. They now measure the element the text actually lands on.
