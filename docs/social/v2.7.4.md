# ColaMD v2.7.4 Social Copy

发布方式：正式版。

## Chinese

ColaMD 2.7.4 发布了。这一版修的是四处「看着没坏、其实坏了」的地方。

**有序列表删掉中间一项，下面的序号会自己接上。** 以前 `1. 2. 3.` 删掉 `2.` 那行，剩下的是 `1. 3.`，后面只能一个个手改。现在序号会跟着你的编辑重排。关键在于改的是**文件本身**，不是只在屏幕上好看：复制出去、用别的软件打开、纯文本导出，序号都是对的，撤销一步能回到改之前。打开文件、Agent 改写文件这些不是你动手的场合，序号一律不动（有人特意把整列写成 `1. 1. 1.` 让 diff 干净，那种写法不会被抹平）。

**查找的「下一个」现在真的会跳。** 以前按下去计数在走、界面不动，得手动滚。这很可能就是「搜索没反应」那个反馈的同一根因：换内核后正文改由编辑器内部的滚动容器托管，跳转还在写外层那个。

**深色主题里选中文字不再被盖住。** 选中色带一直是编辑器内核自带的一套默认色，跟主题无关，深色主题下几乎看不见字。现在跟随主题。

**下载的主题现在真的生效了。** `themes/` 里那 12 份独立主题文件还写着旧内核的选择器（`.ProseMirror`），换内核之后永远匹配不到东西，于是导入一套主题只换了底色，加粗、标题、引用块的颜色纹丝不动。现在全部改成编辑器真实的类名，并且加了一条验收：主题里任何一条规则只要命中不到真实元素，CI 就会红。

顺带两个小的：

- **导出的 HTML 与 PDF 不再丢掉列表起点**：以 `5.` 开头的列表以前会从 1 数起
- **自定义主题多了一份带注释的模板**（`themes/template.css`）：变量和选择器都有现成的写法可以照抄

另外，仓库里那个 VS Code 小扩展（「在 ColaMD 中打开」，0.1.0 的 MVP）撤掉了，一直没维护。

如果你上面哪一条还复现，欢迎开 issue。

下载（macOS 按芯片分，另有 Windows 和 Linux）：
https://github.com/marswaveai/ColaMD/releases/tag/v2.7.4

免费、开源，你的文件永远是最新的。

## English

ColaMD 2.7.4 is out. Four things that looked fine and were not.

**Delete a line from an ordered list and the numbers below it follow.** `1. 2. 3.` used to become `1. 3.` when you removed the middle one, leaving you to renumber by hand. The numbers are now rewritten as you edit, and what changes is the **file itself**, not just the paint on your screen: copy the text out, open it in another app, export it as plain text, the numbers are right, and one undo takes you back. Opening a file and an agent writing to it are not your edits, so nothing is renumbered there (if you keep a whole list at `1. 1. 1.` on purpose for clean diffs, that stays as you wrote it).

**Find next actually moves the view now.** The counter used to advance while the page sat still. This is very likely the same root cause as the earlier "search does not respond" report: after the editor core was replaced, the document scrolls inside the editor's own container, and the jump was still writing to the outer one.

**Selected text is readable in dark themes again.** The selection band came from the editor core's own default palette, unrelated to your theme, and in a dark theme it sat almost on top of the text. It follows the theme now.

**Downloaded themes actually style the editor again.** The twelve standalone files in `themes/` still addressed the DOM of the core we replaced (`.ProseMirror`), so their rules could never match anything: importing one changed the background and nothing else. They now use the class names the editor really emits, and there is a check in CI that fails if any theme rule cannot hit a real element.

Two smaller things:

- **Exported HTML and PDF no longer drop the list start**: a list beginning at `5.` used to export counting from 1
- **Custom themes have a commented template to copy** (`themes/template.css`)

Also: the small VS Code extension ("Open in ColaMD", a 0.1.0 MVP) has been removed from the repository. It had not been maintained.

If any of the above still happens for you, please open an issue.

Download (macOS by chip, plus Windows and Linux):
