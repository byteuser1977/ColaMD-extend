## Chinese

ColaMD 2.7.3 发布了。

这一版有两块。一块是新能力：**本地链接可以跳转了**。

在文档里写 `[方案](doc/方案A.md)` 这种相对路径，按住 `Ctrl`（Windows/Linux）或 `Cmd`（macOS）点击，就在标签页里打开对应文件。中文名、空格文件名都认，绝对路径和 `file://` 也行。链接后面还能带位置：`#标题` 滚到那个标题，`:147` 滚到第 147 行，标题重名时按顺序找第二个、第三个。代码块里那种写着 `# 注释` 的行不会被误判。这条来自社区的需求，实现是 @linxiW1020 写的。

另一块是把 2.7 换内核时漏掉的阅读体验补回来。如果你是从 2.6 升上来的，下面几条大概都碰到了：

- **文首的属性区默认收起了**：2.7 会把那段 YAML 一直露在正文最上面，很突兀。现在整块收起，光标移进去才显示
- **表格格子里的换行真的换行了**（`<br/>`），格子里放图片也能显示
- **表格、图、图片、公式、HTML 这些渲染出来的块，点一下就进到源码**：以前只有公式有这条路，别的块只能去改源文件
- **打开文件夹面板后，正文不再往右偏**
- **大纲不再把代码块里的 `#` 当成标题**
- **待办事项选中时不再变回 `- [ ]` 源码**：复选框一直在，勾没勾还是点出来
- **属性区认中文键**：`标题: 值` 这种以前会被当成正文

Linux 的 AppImage 也换了图标：以前只带一张 1024px，菜单和任务栏按标准尺寸去找都找不到，只能退成通用图标。

还有一个小的：加粗的时间戳（`**00:28:02 开场**`）以前会被染成绿色。

以上任何一条，如果你之前遇到过、装上这版还在，欢迎开一个 Issue。

下载（macOS 按芯片选，Windows 与 Linux 各一份）：

免费、开源，文件永远是最新的。

## English

ColaMD 2.7.3 is out.

Two parts this time. The first is new: **local links now navigate**.

Write a relative path like `[plan](doc/plan.md)` and hold `Ctrl` (Windows/Linux) or `Cmd` (macOS) while clicking. The file opens in a tab. Chinese and space-containing filenames work, as do absolute paths and `file://` URLs. A link can also carry a position: `#heading` scrolls to that heading and `:147` scrolls to line 147, with repeated headings resolving in order. A `# comment` inside a code block is not mistaken for a heading. This one came from the community, implemented by @linxiW1020.

The second part is the reading experience that 2.7 dropped when the editor core was replaced. If you came from 2.6, you likely ran into all of these:

- **Frontmatter is folded by default**: 2.7 left that YAML block sitting at the top of the document. It now stays folded until your cursor goes into it
- **A `<br/>` inside a table cell actually breaks the line**, and images render in cells
- **Rendered blocks can be clicked into**: tables, diagrams, images, formulas and HTML blocks now put the cursor into their source. Before, only formulas had that path
- **The text no longer shifts right when the file panel is open**
- **The outline no longer picks up `#` inside code blocks**
- **Selecting a task item no longer turns the checkbox back into `- [ ]` source**
- **Frontmatter keys can be Chinese**: `标题: value` used to be treated as body text

The Linux AppImage has a new icon set: it used to ship a single 1024px icon, so menus and taskbars looking for standard sizes fell back to a generic icon.

One more small fix: a bold timestamp (`**00:28:02 Intro**`) used to be painted green.

If any of the above still happens for you, please open an issue.

Download (macOS by chip, plus Windows and Linux):
https://github.com/marswaveai/ColaMD/releases/tag/v2.7.3

Free, open source, and your files stay up to date.
